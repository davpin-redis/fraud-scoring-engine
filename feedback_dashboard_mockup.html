Cross-instance by construction. These are not per-engine `/actuator` numbers. Every engine appends its decision to the shared txn:events Redis Stream; a metrics aggregator joins those decisions with the label store and maintains global confusion counters in Redis (metrics:{modelVersion}:{minute} → tp/fp/fn/tn). This page reads the aggregator over SSE, so the figures already span all instances and survive restarts / autoscaling.
Label latency. Recall / precision / FP-rate need ground truth, which in production lags (chargebacks days later); this live view is exact only because the test supplies labels immediately (seeded scenario + approved-but-fraud marks). Both metrics improve together only because the challenger has better discrimination, shown by it sitting at a strictly better operating point on the same labelled holdout — not by moving a threshold.
